# KAIPY - AI-Integrated E-Commerce Platform

Dự án Đồ án Tốt nghiệp E-Commerce tích hợp Phân hệ AI Engine (ChromaDB + Google Gemini API).

## Cấu trúc dự án
- `frontend/`: Giao diện người dùng (HTML, Tailwind CSS).
- `database/`: File khởi tạo CSDL MySQL (schema & seed data).
- `backend/`: RESTful API Server (Node.js/Express).
- `ai-engine/`: Microservice AI RAG Search & Advisory (Python FastAPI).
